# v0.1.0 — research preview

> Draft only. Do not publish until `RELEASE_READINESS.md` records a GO decision for the tagged SHA.

VIGIL explores runtime least authority for autonomous AI agents. This preview includes a portable
Rust decision/gateway core, causal provenance, signed bounded capabilities, budgets, specific
approvals, semantic filesystem/process/network/Git/MCP/secret brokers, risk and incident response,
tamper-evident audit, a dependency-free Python SDK, and native macOS adapter/product code tested
without restricted entitlements.

## Review paths

- Run `make recruiter-demo` for the four-part local walkthrough.
- Run `make evaluate` for release, adversarial and detection-quality evaluation.
- Read `docs/START_HERE.md` for five-, fifteen- and thirty-minute paths.
- Read `docs/security/ENFORCEMENT_STATUS.md` before interpreting any native claim.

## Important limitation

This release does **not** demonstrate signed, entitled, activated Endpoint Security or Network
Extension enforcement and does not confine arbitrary macOS process syscalls. Same-user approval
and storage isolation also remain future daemon work. It is a research artifact, not a production
endpoint-security warranty.
